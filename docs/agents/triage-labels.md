# Triage labels

Map canonical triage roles to the existing Linear team labels.

| Role | Linear label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue. |
| needs-info | needs-info | Waiting on the reporter for more information. |
| ready-for-agent | ready-for-agent | Fully specified and ready for agent implementation. |
| ready-for-human | ready-for-human | Requires human implementation. |
| wontfix | wontfix | Will not be actioned. |

Reuse these labels. Do not create synonymous labels.

Readiness labels do not replace native issue status, dependencies, or the
user's authorization. Do not infer an automatic label-removal policy.
